# TypeScript Demo

Демонстраційний проєкт для навчання TypeScript та роботи з Git-гілками.  
Основні гілки:
- `main` — збережена стабільна версія
- `develop` — активна розробка

У репозиторії створено приклад вихідного файлу на TypeScript (`src/index.ts`) та базову конфігурацію компілятора (`tsconfig.json`).  
Зкомпільований код зберігається у директорії `dist`.

## Команди
- `npm run build` — компілює TypeScript у `dist`
- `npm start` — виконує зкомпільований код
- `npm run dev` — запуск у режимі розробки
